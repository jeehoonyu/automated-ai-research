# Redistributable benchmark

All text fixtures in this directory are synthetic and distributed under the repository's Apache-2.0
license. PDF fixtures are generated deterministically during tests so the repository does not rely on
third-party copyrighted papers.

The corpus includes a supported result, an independent contradiction, a methodology limitation,
prompt-injection text, and an insufficient-evidence path. Integration tests add text, table, raster,
vector, malformed, and image-only PDFs.
